Measured synthetic evidence

Two five-epoch runs used 24 geometric fixtures with distinct mock patient IDs: 16 train, 4 validation and 4 test. Seed 42, Adam 1e-4, batch size 4.

The hybrid predicted all four test fixtures positive at threshold 0.5. AUC measures ranking, so AUC 1.0 can coexist with poor threshold accuracy on this four-example test set. These numbers establish no medical performance or model superiority.

Architecture

128×128 grayscale crop → Conv(1,32,3) → ReLU → MaxPool(2) → Conv(32,64,3) → ReLU → MaxPool(2) → flatten 57,600 → Linear(57,600,8) → RX AngleEmbedding → three BasicEntanglerLayers → eight Pauli-Z expectations → Linear(8,1) → sigmoid.

The quantum block is a variational quantum layer, not a full QCNN with quantum pooling.
